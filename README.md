## ✨ ฟีเจอร์หลัก (Features)

* **✏️ แก้ไขข้อมูลสดบนหน้าเว็บ (Live Edit Mode):**
  * เปิด/ปิดโหมดแก้ไขได้ทันทีจากแถบเมนูด้านบน (`แก้ไขข้อมูล`) เพื่อคลิกแก้ไขข้อความทุกส่วนบนหน้าเว็บผ่าน `contentEditable`
  * รองรับการอัปโหลดเปลี่ยนรูปโปรไฟล์จากเครื่องได้ทันที (แปลงเป็น Base64)
  * บันทึกข้อมูลการแก้ไขทั้งหมดลงใน `localStorage` ของเบราว์เซอร์โดยอัตโนมัติ พร้อมปุ่ม **รีเซ็ตค่าเริ่มต้น**
* **🎨 ดีไซน์ Minimal Earth Tone & Dark Mode:**
  * ชุดสีธรรมชาติที่อบอุ่น สบายตา (`Warm Cream`, `Warm Sand`, `Espresso Brown`, `Sage Green`, `Terracotta Clay`)
  * รองรับการสลับธีมโหมดสว่าง (Warm Cream) และโหมดมืด (Deep Espresso) พร้อมจดจำค่าธีมที่เลือก
* **📂 ระบบจัดการผลงานและกิจกรรม (Projects & Reflection Showcase):**
  * กรองดูผลงานตามหมวดหมู่เกณฑ์ TCAS: **วิชาการและวิจัย**, **จิตอาสาและพัฒนาชุมชน**, และ **ผู้นำและกิจกรรม**
  * คลิกที่การ์ดผลงานเพื่อเปิดหน้าต่าง Modal แสดงรายละเอียด บทบาทหน้าที่ และ **การถอดบทเรียนทางสังคมศาสตร์ (Reflection)** สำหรับเตรียมตอบคำถามสอบสัมภาษณ์
  * สามารถเพิ่มผลงานใหม่ (`+ เพิ่มผลงาน`) หรือลบผลงานที่ไม่ต้องการได้ทันทีบนหน้าเว็บ
* **🖨️ จัดหน้าพร้อมพิมพ์และบันทึกเป็น PDF (Print-Ready):**
  * มีปุ่ม **พิมพ์ / บันทึกเป็น PDF** ที่ใช้ `@media print` ปรับพื้นหลังเป็นสีขาว ซ่อนแถบเมนูและปุ่มควบคุมที่ไม่จำเป็น เพื่อให้ได้ไฟล์ PDF ที่เป็นระเบียบพร้อมยื่น

## 📑 โครงสร้างเนื้อหาภายในเว็บไซต์

1. **หน้าแรก (Hero Section):** ข้อมูลแนะนำตัว โรงเรียนธัญรัตน์ แผนการเรียนศิลป์-ธุรกิจการค้าสมัยใหม่ เกรดเฉลี่ยสะสม (GPAX 3.88) และป้ายกำกับสาขาที่สนใจ
2. **ประวัติส่วนตัว & Statement of Purpose (SOP):** เหตุผลและแรงบันดาลใจในการเลือกเรียนคณะสังคมศาสตร์ ข้อมูลส่วนบุคคล คุณลักษณะเด่น และไทม์ไลน์ประวัติการศึกษา (โรงเรียนธัญรัตน์ และ โรงเรียนอุดมวิทยา)
3. **ทักษะ & ผลการเรียน (Competencies & Grades):** ระดับทักษะทางสังคมศาสตร์ เกรดเฉลี่ยรายวิชาสำคัญ (สังคมศึกษา 4.00, ประวัติศาสตร์ 4.00, ภาษาไทย 4.00, ภาษาต่างประเทศ 3.85) และทักษะภาษา/เครื่องมือวิจัย
4. **ผลงานและกิจกรรม (Activities & Research Works):** การ์ดแสดงผลงานวิจัย กิจกรรมจิตอาสา และบทบาทผู้นำ พร้อมระบบกรองหมวดหมู่และหน้าต่างถอดบทเรียน
5. **เกียรติบัตรและรางวัล (Certificates & Honours):** รายการรางวัลและการแข่งขันทางวิชาการและจิตอาสา
6. **ช่องทางติดต่อ & อาจารย์ผู้รับรอง (Contact & Teacher Reference):** ข้อมูลติดต่อผู้สมัคร และช่องกรอกข้อมูลติดต่ออาจารย์ประจำชั้น/อาจารย์ที่ปรึกษาโครงงานพร้อมคำรับรอง[cite: 2]

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

* **HTML5** — โครงสร้างหน้าเว็บแบบไฟล์เดียวจบ (Single-File Application)
* **Tailwind CSS (CDN)** — จัดการ Layout, Responsive Design และการตั้งค่าสี Custom Theme (`earth.*`)
* **Vanilla JavaScript (ES6+)** — จัดการระบบ `contentEditable`, `localStorage`, การกรอง/เพิ่ม/ลบผลงาน และ Modal
* **Google Fonts** — ใช้ฟอนต์ **Prompt**, **Sarabun** และ **Inter**
* **Lucide Icons** — ไอคอนสไตล์มินิมอล[cite: 2]

## 🚀 วิธีการใช้งาน (How to Use)

1. **เปิดไฟล์:** ดับเบิลคลิกไฟล์ `e_portfolio_tcas (3).html` เพื่อเปิดบนเว็บเบราว์เซอร์ (เช่น Google Chrome, Microsoft Edge, Safari)
2. **แก้ไขข้อมูลส่วนตัว / เพิ่มข้อมูลอาจารย์ที่ปรึกษา:**
   * คลิกที่ข้อความที่ต้องการแก้ไขแล้วพิมพ์ข้อมูลเพิ่มเติมได้ทันที (เช่น ชื่อและเบอร์ติดต่ออาจารย์ที่ปรึกษาในส่วนท้าย หรืออัปเดตข้อความคำรับรอง)
   * นำเมาส์ไปวางที่รูปโปรไฟล์แล้วคลิก **"เปลี่ยนรูปโปรไฟล์"** เพื่ออัปโหลดรูปภาพชุดนักเรียนหรือชุดสุภาพ
   * เมื่อแก้ไขเสร็จ ให้กดปุ่ม **"เสร็จสิ้น"** ที่แถบสีเขียวด้านบนเพื่อบันทึกข้อมูลและปิดกรอบเส้นประ
3. **เพิ่มหรือลบผลงาน:**
   * กดปุ่ม **"+ เพิ่มผลงาน"** ในส่วนผลงานและกิจกรรมเพื่อเพิ่มรายการใหม่
   * คลิกที่การ์ดผลงานใดๆ แล้วกดปุ่ม **"ลบผลงานนี้"** ด้านล่างหน้าต่างหากต้องการนำออก
4. **ส่งออกเป็นไฟล์ PDF:** กดปุ่ม **"พิมพ์ / บันทึกเป็น PDF"** แล้วเลือกปลายทางเป็น **Save as PDF** เพื่อนำไปอัปโหลดในระบบรับสมัคร TCAS[cite: 2]

## 💾 การจัดเก็บข้อมูล (Local Storage Keys)

เว็บไซต์บันทึกข้อมูลที่แก้ไขไว้ในเบราว์เซอร์ผ่านคีย์ดังต่อไปนี้:
* `eportfolio_socsci_texts_v1` — ข้อความทั้งหมดที่มีแอตทริบิวต์ `data-editable`
* `eportfolio_socsci_profile_img_v1` — ข้อมูลรูปภาพโปรไฟล์
* `eportfolio_socsci_projects_v1` — รายการผลงานและกิจกรรมทั้งหมด
* `eportfolio_thai_theme_v1` — ค่าการตั้งค่าโหมดมืด/สว่าง (`dark` / `light`)

> **หมายเหตุ:** เนื่องจากข้อมูลที่แก้ไขผ่านหน้าเว็บจะถูกบันทึกไว้ใน `localStorage` ของเบราว์เซอร์บนเครื่องที่ใช้งาน หากต้องการนำไฟล์ไปเผยแพร่ออนไลน์ (เช่น GitHub Pages หรือ Netlify) ควรแก้ไขข้อมูลในโค้ด HTML โดยตรงเพื่อให้ผู้เข้าชมทุกคนเห็นข้อมูลที่เป็นปัจจุบัน[cite: 2]
