# 🌿 E-Portfolio — คณะสังคมศาสตร์ (Minimal Earth Tone Edition)

เว็บไซต์แฟ้มสะสมผลงานออนไลน์ (E-Portfolio) สไตล์ **Minimal Earth Tone** ออกแบบมาสำหรับนักเรียนระดับชั้นมัธยมศึกษาตอนปลาย เพื่อใช้ยื่นสมัครเข้าศึกษาต่อใน **คณะสังคมศาสตร์ (Faculty of Social Sciences)** ระบบ TCAS รอบที่ 1 (Portfolio)

พัฒนาในรูปแบบ Single-Page Web Application (ไฟล์เดียวจบ) รองรับการแก้ไขข้อมูลบนหน้าเว็บได้ทันทีโดยไม่ต้องเขียนโค้ดเพิ่ม และจัดรูปแบบการพิมพ์ (Print / Export PDF) ที่สวยงามพร้อมยื่นคณะกรรมการสัมภาษณ์

---

## ✨ คุณสมบัติเด่น (Key Features)

* **🎨 ดีไซน์ Minimal Earth Tone & Dark Mode:**
  * โทนสีธรรมชาติที่อบอุ่นและสบายตา (ครีมเบจ, ทรายอุ่น, น้ำตาลเอสเพรสโซ, เขียวเซจ และดินเผาเทอร์ราคอตตา)
  * รองรับการสลับโหมดสว่าง (Warm Cream) และโหมดมืด (Deep Espresso)
* **✏️ ระบบแก้ไขข้อมูลสดบนหน้าเว็บ (Live Edit Mode):**
  * คลิกปุ่ม **"แก้ไขข้อมูล"** เพื่อคลิกแก้ไขข้อความได้ทุกส่วนบนหน้าเว็บ (ชื่อ, โรงเรียน, GPAX, SOP, ประวัติการศึกษา, ทักษะ, และข้อมูลติดต่อ)
  * สามารถอัปโหลดเปลี่ยนรูปโปรไฟล์ได้จากเครื่องทันที
  * บันทึกข้อมูลอัตโนมัติลงใน `localStorage` ของเบราว์เซอร์ (พร้อมปุ่มรีเซ็ตกลับเป็นค่าเริ่มต้น)
* **📚 โครงสร้างเนื้อหาเฉพาะทางสำหรับคณะสังคมศาสตร์ (TCAS):**
  * **Statement of Purpose (SOP):** พื้นที่ถ่ายทอดแรงบันดาลใจ เป้าหมายการศึกษา และตัวตนของผู้สมัคร
  * **ผลการเรียนรายวิชาสำคัญ:** แสดงเกรดเฉลี่ยรายวิชาหลัก (สังคมศึกษา, ประวัติศาสตร์, ภาษาไทย, ภาษาอังกฤษ) และทักษะการทำวิจัยเชิงคุณภาพ
  * **ผลงานและการถอดบทเรียน (Projects & Reflection):** จัดหมวดหมู่ตามเกณฑ์ TCAS (*วิชาการและวิจัย / จิตอาสาและพัฒนาชุมชน / ผู้นำและกิจกรรม*) พร้อมหน้าต่าง Modal แสดง **บทบาทหน้าที่** และ **สิ่งที่ได้เรียนรู้ (Reflection)** รวมถึงฟีเจอร์เพิ่มผลงานใหม่ได้ทันที
  * **อาจารย์ผู้รับรอง (Teacher Reference):** ส่วนแสดงข้อมูลติดต่อและคำรับรองจากอาจารย์ที่ปรึกษา
* **🖨️ พร้อมพิมพ์และบันทึกเป็น PDF (Print-Ready):**
  * มีปุ่ม **"พิมพ์ / PDF"** ที่ปรับ Layout สำหรับกระดาษ A4 อัตโนมัติ ซ่อนปุ่มเมนูที่ไม่จำเป็น เพื่อให้ได้ไฟล์ PDF ที่เป็นระเบียบเรียบร้อย

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

* **HTML5** — โครงสร้างหน้าเว็บแบบ Semantic HTML
* **Tailwind CSS (via CDN)** — จัดการ Layout, Responsive Design และระบบสี Custom Earth Tone
* **Vanilla JavaScript (ES6+)** — ระบบจัดการ State, Live ContentEditable, LocalStorage Persistence, ระบบกรองผลงาน และ Modal
* **Google Fonts** — จับคู่ฟอนต์ภาษาไทย **Prompt** (สำหรับหัวข้อ) และ **Sarabun** (สำหรับเนื้อหาให้อ่านง่าย)
* **Lucide Icons** — ไอคอนสไตล์มินิมอลเส้นบาง

## 🚀 วิธีการใช้งาน (Getting Started)

1. **ดาวน์โหลดไฟล์:** บันทึกไฟล์ `index.html` ลงในเครื่องของคุณ
2. **เปิดใช้งาน:** ดับเบิลคลิกไฟล์ `index.html` เพื่อเปิดผ่านเว็บเบราว์เซอร์ใดก็ได้ (Chrome, Safari, Edge, Firefox) โดยไม่ต้องติดตั้งโปรแกรมเสริมหรือรัน Server
3. **ปรับแต่งข้อมูลส่วนตัว:**
   * กดปุ่ม **"แก้ไขข้อมูล"** ที่แถบเมนูด้านบนขวา
   * คลิกที่ข้อความที่ต้องการแก้ไขแล้วพิมพ์ข้อมูลของคุณ
   * คลิกที่รูปโปรไฟล์เพื่อเลือกรูปภาพใหม่
   * กดปุ่ม **"บันทึกข้อมูล"** เมื่อเสร็จสิ้น
4. **เพิ่มผลงานใหม่:** กดปุ่ม **"+ เพิ่มผลงาน"** ในหมวดผลงานและกิจกรรม กรอกชื่อผลงาน หมวดหมู่ บทบาท และการถอดบทเรียน
5. **ส่งออกเป็นไฟล์ PDF:** กดปุ่มไอคอนเครื่องพิมพ์ (**พิมพ์ / PDF**) เลือกปลายทางเป็น *Save as PDF* เพื่อนำไปใช้งาน
